0. 使用前先记住

0.1 快捷键取决于鼠标所在区域

Blender 的快捷键高度依赖上下文。同一个按键在 3D Viewport、Outliner、Timeline、Shader Editor 中可能执行不同命令。

  • 操作前先把鼠标移到目标编辑器区域。
  • G 在 3D Viewport 中移动物体，在节点编辑器中移动节点。
  • A 通常表示全选，但只选择鼠标所在编辑器中的内容。
  • 1、2、3 与 Numpad 1、Numpad 2、Numpad 3 是不同按键。

0.2 本文采用 Blender Default Keymap

Blender 首次启动时可选择 Blender 或 Industry Compatible 键位。本文只对应默认的 Blender 键位。

在 Keymap 中可以搜索命令、查看冲突、修改绑定和恢复默认值。

0.3 没有数字键盘怎么办

进入：

启用后，主键盘上方的数字键可模拟数字键盘视图操作，但会影响编辑模式下 1、2、3 的点线面切换。小键盘不完整时，也可以按 Accent Grave（反引号键）打开视图导航饼菜单。

0.4 鼠标操作约定

写法 含义
LMB 鼠标左键
RMB 鼠标右键
MMB 鼠标中键 / 按下滚轮
Wheel 滚轮滚动
Accent Grave 反引号键，通常位于数字 1 左侧

macOS 上 Alt 对应 Option。文件和系统操作可能显示 Cmd，但 Blender 视图与建模键位通常仍按 Keymap 中显示的 Ctrl、Alt 执行。

1. 一分钟核心键位

1.1 必须先形成肌肉记忆

快捷键 作用 说明
F3 Operator Search 忘记快捷键时直接搜索命令名
Tab 物体模式 / 编辑模式 建模时使用频率最高
G Grab / Move 移动
R Rotate 旋转
S Scale 缩放
X / Y / Z 轴约束 在 G/R/S 后按下
Shift + X/Y/Z 排除某一轴 例如 S → Shift + Z 只缩放 XY
Shift + A Add 添加网格、灯光、相机等
X Delete 菜单 删除物体、顶点、边或面
Ctrl + Z Undo 撤销
Ctrl + Shift + Z Redo 重做
Ctrl + S Save 保存当前 .blend 文件
F9 Adjust Last Operation 调整刚执行操作的参数

1.2 变换命令的通用节奏

Blender 的变换通常遵循：

输入序列 结果
G → X → 2 → Enter 沿 X 轴移动 2 米
R → Z → 90 → Enter 绕 Z 轴旋转 90°
S → 2 → Enter 整体放大两倍
S → Z → 0 → Enter 将选中元素在 Z 轴压平
G → X → X 沿物体局部 X 轴移动
操作中按 Esc 或 RMB 取消本次操作
操作中按 LMB 或 Enter 确认本次操作

输入负数可以反向变换；按 / 可以输入除法，例如 S → 2 → / → 3。

6. 物体模式

6.1 创建与复制

快捷键 作用
Shift + A 添加物体
Shift + D 普通复制，复制独立数据
Alt + D 关联复制，共享 Mesh Data
X 删除选中物体
M 移动到 Collection

Alt + D 适合重复窗户、路灯、树木等实例。进入编辑模式修改其中一个，其他关联副本会同步变化。

6.2 层级与组合

快捷键 作用
Ctrl + P 设置父对象
Alt + P 清除父级关系
Ctrl + J 合并为一个对象
P 编辑模式中将选中网格分离为对象

Ctrl + J 会以最后选中的活动对象为目标，名称、原点和部分数据取活动对象设置。

6.3 常用快速修改器

快捷键 作用
Ctrl + 1 添加 / 设置一级 Subdivision Surface
Ctrl + 2 设置二级细分
Ctrl + 3 设置三级细分

高细分级别会明显增加网格计算量，不要习惯性使用过高等级。

14. 快捷键失效排查

14.1 检查鼠标所在编辑器

快捷键只发送给鼠标所在区域。想操作模型时，确保鼠标位于 3D Viewport，而不是 Outliner、Properties 或 Timeline。

14.2 检查当前模式

  • E 挤出需要 Edit Mode。
  • Ctrl + A 应用变换需要 Object Mode。
  • 1/2/3 只有 Edit Mode 才切换点、边、面。
  • Ctrl + J 需要 Object Mode 且至少选择两个可合并对象。

14.3 检查键位方案

确认当前选择的是 Blender，而不是 Industry Compatible 或自定义 Keymap。

14.4 检查数字键盘模拟

启用 Emulate Numpad 后，主键盘数字会优先模拟视图按键，可能无法直接切换点、边、面选择模式。

14.5 用 F3 查命令

记得命令名但忘记按键时，按 F3 搜索。搜索结果右侧通常会显示当前绑定；也能直接执行没有默认快捷键的命令。

14.6 查看最后一步参数

操作结果不符合预期时先按 F9。很多命令的段数、方向、偏移、合并方式都可以在 Adjust Last Operation 中修改，不必立即撤销重做。
