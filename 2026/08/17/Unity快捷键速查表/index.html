xiaoyunhai2026-08-172026-08-17

面向 Unity 程序、美术和技术美术的 Editor 快捷键速查表。按“现在要做什么”分类，优先收录高频、稳定、能明显减少鼠标操作的快捷键。

Unity 版本、系统、键盘布局、已安装 Package 和自定义 Profile 都可能改变绑定；当前项目的最终结果以 Shortcuts 窗口为准。

0. 使用约定

0.1 Windows Linux 与 macOS 对照

文中写法 Windows / Linux macOS
Ctrl/Cmd Ctrl Command (⌘)
Alt/Option Alt Option (⌥)
Shift Shift Shift (⇧)
Delete Delete Delete 或 Fn + Delete，取决于键盘
Enter/Return Enter Return

除非单独说明，正文以 Windows 键位名称展示。看到 Ctrl/Cmd + S 时，Windows/Linux 使用 Ctrl + S，macOS 使用 Cmd + S。

0.2 全局快捷键和上下文快捷键

  • 全局快捷键：不管当前聚焦哪个窗口都能执行，例如 Ctrl/Cmd + Z。
  • 上下文快捷键：只在特定窗口或工具激活时生效，例如 Animation 中的 , 和 .。
  • 同一个按键可以在不同上下文执行不同操作。例如普通 Scene 中 W 是 Move Tool，按住右键进入 Flythrough 后 W 是向前飞行。
  • 表格中的“窗口需聚焦”表示先把鼠标放到窗口中点击一下，再按快捷键。

0.3 如何确认自己版本的真实绑定

在 Shortcuts 窗口中可以：

  • 搜索命令名称和当前按键。
  • 查看 Global、Scene View、Hierarchy、Animation、Timeline 等分类。
  • 检查黄色警告标记的绑定冲突。
  • 恢复单个命令默认值。
  • 创建、切换、导入和导出快捷键 Profile。

Unity 2019.1 之后，官方不再维护一张适用于所有安装环境的静态总表，因为 Package 和自定义工具也能注册快捷键。本文覆盖内置稳定键位与常见 Package 上下文，完整安装清单仍应在 Shortcuts 窗口中查看。

快捷键 作用 说明

Ctrl/Cmd + O 打开场景 打开 Scene 资源
Ctrl/Cmd + S 保存场景 高频键位
Ctrl/Cmd + Shift + S 场景另存为 复制关卡模板时常用
Ctrl/Cmd + Shift + B 打开 Build Profiles / Build Settings 名称随 Unity 版本变化
Ctrl/Cmd + B Build And Run 部分新版或自定义 Profile 可能不同
Alt + F4 Windows/Linux 关闭 Unity 有未保存内容时会确认
Cmd + Q macOS 退出 Unity macOS 系统级快捷键

2.2 通用编辑

快捷键 作用 常见场景
Ctrl/Cmd + Z Undo Transform、Inspector、创建删除对象
Ctrl + Y Windows/Linux Redo 重做被撤销操作
Cmd + Shift + Z macOS Redo macOS 默认习惯
Ctrl/Cmd + X Cut GameObject、资源、文本
Ctrl/Cmd + C Copy GameObject、资源、组件、文本
Ctrl/Cmd + Insert Copy 的备用键位 Unity 当前内置 Alternative Binding
Ctrl/Cmd + V Paste 粘贴到当前上下文
Shift + Insert Paste 的备用键位 Unity 当前内置 Alternative Binding
Ctrl/Cmd + Shift + V Paste As Child Hierarchy 中粘贴为子节点
Ctrl/Cmd + D Duplicate 比复制粘贴更快
Ctrl/Cmd + A Select All 只选择当前窗口上下文中的内容
Delete Delete 删除选中对象、资源、关键帧等
Shift + Delete 直接删除或旧版删除命令 Project 中可能跳过确认，使用前看提示

2.3 Play Mode

快捷键 作用 使用方式
Ctrl/Cmd + P Play / Stop 快速进入和退出运行模式
Ctrl/Cmd + Shift + P Pause / Resume 冻结游戏状态后检查 Scene 与 Inspector
Ctrl/Cmd + Alt + P Step 暂停时推进一帧

常见调试组合

Play Mode 注意事项

  • 默认情况下，Play Mode 修改的场景对象数值会在退出时恢复。
  • 暂停只暂停 Player 循环，不会阻止所有 Editor 工具和 Inspector 操作。
  • Step 推进的是一个 Editor/Player 更新步，不保证只执行一次 FixedUpdate。
  • 开启 Enter Play Mode Options 后，脚本重载和场景重载行为可能改变，但快捷键不变。

3.6 Pivot Center 与 Local Global

经典 Unity Profile 常见：

快捷键 作用 版本提示
Z Pivot / Center 切换 新版包含更多 Tool Settings 时请在 Shortcuts 中确认
X Local / Global 切换 Unity 6 还可能出现 Grid 方向，具体以 Profile 为准
  • Pivot：手柄位于对象真实 Pivot。
  • Center：手柄位于多选对象包围中心。
  • Local：手柄方向跟随对象旋转。
  • Global：手柄方向使用世界坐标。
  • Grid：Unity 6 中可让手柄方向跟随自定义网格。

5. 选择聚焦与场景可见性

5.1 单选与多选

操作 作用
左键单击对象 选择单个 GameObject
拖选框 选择框内多个 GameObject
Shift + 单击 添加到选择，或改变多选中的 Active Object
Ctrl/Cmd + 单击 添加或移除单个对象
Ctrl/Cmd + A 选择当前窗口上下文中的全部对象
单击空白 清空选择

多选时最后选择的对象通常是 Active Object。对齐、设置父级、Pivot 计算等需要单个基准对象的操作会使用它。

5.2 内置选择命令

快捷键 菜单命令 作用
Shift + D Edit > Deselect All 清空当前选择
Shift + C Edit > Select Children 选择当前对象的子对象
Ctrl/Cmd + Shift + R Edit > Select Prefab Root 从实例子节点跳到 Prefab 实例根对象
Ctrl/Cmd + I Edit > Invert Selection 反选当前上下文中的对象

这些命令由当前聚焦窗口处理。在 Hierarchy、Project 或其它窗口中执行时，选择范围可能不同。

5.3 前后选择历史

快捷键 菜单命令 作用
Ctrl/Cmd + Shift + [ Edit > Previous Selection 返回上一次选择
Ctrl/Cmd + Shift + ] Edit > Next Selection 前进到下一次选择

适合在 Player、Camera、Prefab 和材质之间来回检查，不需要反复在 Hierarchy 或 Project 中搜索。

5.4 保存与载入 Selection 1-9

快捷键 命令 作用
Ctrl/Cmd + Alt/Option + 1...9 Save Selection 1…9 把当前选择保存到对应编号
Ctrl/Cmd + Shift + 1...9 Load Selection 1…9 恢复对应编号中的选择

这是经典 Unity 版本和部分 Shortcut Profile 中的 Selection Sets 键位。若当前版本无效，请在 Shortcuts 中搜索 Save Selection、Load Selection 或 Selection 1；搜索不到表示当前 Editor 没有注册该组命令。

5.5 重叠对象穿透选择

操作 作用
Ctrl/Cmd + 右键 打开光标位置的重叠对象列表
Ctrl/Cmd + Shift + 右键 从列表选择并加入当前多选
在重叠位置重复单击 在可选对象之间循环

5.6 聚焦资源和对象

快捷键 当前窗口 作用
F Scene 镜头聚焦选中 GameObject
F Project 在所在文件夹中定位选中资源
F Animation 聚焦选中的关键帧或曲线
A Animation / Timeline 显示全部关键帧或完整时间范围

5.7 Scene 可见性

操作 作用
H 隐藏 / 显示选中对象及其全部后代
L 禁止 / 恢复选中对象及其全部后代被 Scene 鼠标拾取
Shift + H 隔离显示选中对象及其全部后代
再按 Shift + H 退出隔离模式
点击 Hierarchy 眼睛图标 在 Scene 中隐藏/显示对象及子级
Alt + 点击眼睛图标 只切换当前 GameObject，不递归子级

Scene Visibility 只影响 Editor Scene 视图，不会停用 GameObject，也不会直接改变构建后的运行结果。
Scene Picking 的 L 只阻止在 Scene 视图中点选，仍可在 Hierarchy 中选中，也不改变运行时 Collider 或射线检测。

Vertex Snap 按住 V + 拖 顶点对顶点或顶点对表面

6.2 顶点吸附

组合 作用
V + 拖 顶点吸附到目标顶点
V + Shift + Ctrl/Cmd + 拖 顶点吸附到目标表面
V + Shift + 拖 使用对象 Pivot 吸附到目标顶点

6.3 Unity 6 网格快捷键

快捷键 命令 作用
\ Toggle Snapping 开关网格吸附
Ctrl/Cmd + \ Push To Grid 将选中对象推到最近网格点
Ctrl/Cmd + Shift + \ Align To Grid 将对象旋转对齐网格方向
Ctrl/Cmd + [ Decrease Grid Size 缩小网格尺寸
Ctrl/Cmd + ] Increase Grid Size 放大网格尺寸

7. Hierarchy层级操作

7.1 GameObject Set Active / Inactive（启用与禁用）

快捷键 / 操作 命令 作用
Alt/Option + Shift + A GameObject > Toggle Active State 切换一个或多个选中 GameObject 的激活状态
Inspector 顶部 Active 复选框 Active 直接设置当前 GameObject 的激活状态

多选时怎么切换

Toggle Active State 不是让每个对象分别取反，而是读取 Active Object 的 activeSelf，再把全部选中对象统一设成相反值：

Active Object 当前状态 执行后的结果
activeSelf == true 全部选中对象设为 Inactive
activeSelf == false 全部选中对象设为 Active

三种“隐藏 / 禁用”不要混用

状态 含义 Alt/Option + Shift + A 是否影响
activeSelf GameObject 自己保存的 Active 状态 是
activeInHierarchy 综合父级后，在场景层级中的实际激活状态 间接影响，只读
Scene Visibility 眼睛图标 只在 Editor Scene 中临时隐藏 否
Component 的 Enabled 复选框 只禁用该组件，例如 Renderer、Collider 或脚本 否

父对象为 Inactive 时，子对象即使 activeSelf == true，activeInHierarchy 仍然是 false。重新启用父对象后，子对象会恢复它自己的 activeSelf 状态。

17. 快捷键失效排查

17.1 先按顺序检查

  1. 窗口是否获得焦点：先点击 Scene、Project、Animation 或 Timeline 空白处。
  2. 是否正在输入文字：搜索框、重命名框、数值框会吃掉按键。
  3. 当前工具上下文是否正确：例如 Flythrough 中 W 不再切 Move Tool。
  4. 是否发生绑定冲突：Shortcuts > Binding Conflicts。
  5. Profile 是否被切换：确认当前激活的 Profile。
  6. Package 是否改变绑定：新装 ProBuilder、Timeline、Terrain、2D 工具后检查冲突。
  7. 系统是否拦截：输入法、显卡工具、录屏软件、窗口管理器可能抢占按键。
  8. 键盘布局是否不同：``、'、;、[、] 在不同布局上位置不同。
  9. 版本是否变化：升级 Unity 后对照 Default Profile。

17.2 常见现象

现象 常见原因 处理
W 不能切 Move Tool 正按住右键或输入框聚焦 松开右键，点击 Scene 空白
F 没聚焦对象 Scene 没焦点或没有选择对象 点击 Scene，再选择对象按 F
Space 开始了动画而不是最大化 Animation/Timeline 上下文接管 最大化使用 Shift + Space
Delete 没删对象 文本框聚焦或系统键不同 退出输入，检查 Shortcuts
Ctrl + K 被 IDE 或系统占用 Unity 不在前台或系统冲突 切回 Unity，重新绑定 Search
\ 无法切网格 键盘布局不同 给 Toggle Snapping 换键
Package 快捷键装完就冲突 新命令与 Global Command 重复 在 Binding Conflicts 中处理
Mac 上 Ctrl 组合无效 应使用 Command 按本文 Ctrl/Cmd 映射
